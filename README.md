# SparkDemo1
Multimodal sentiment (autonomic signals) analysis and dashboard

#Phase 1: Multimodal sentiment (autonomic signals) analysis and dashboard


In phase 1, we will use video and audio from the online available dataset. 
The audio data will be first converted into text using Natural Language Processing(NLP) for sentiment analysis.  We will employ lightweight computer vision techniques for video sentiment analysis. 

The sentiment analysis data of both audio and video will be fused using multimodal data fusion methods to extract the valuable outcome. We will design a dashboard for a user-friendly visualisation of the results.
